
# Django REST Framework - Student Management API

A RESTful API built using Django REST Framework to manage students, courses, and enrollments.

## Technologies Used
- Python
- Django & Django REST Framework
- PostgreSQL
- JWT & Token Authentication
- Postman

## Features
- Student and Course CRUD operations
- REST API using GET, POST, PUT, PATCH, DELETE
- ModelSerializer and Custom Validation
- Nested Serialization and Serializer Inheritance
- Token and JWT Authentication
- Permissions and Authorization
- Generic API Views
- API Pagination

## Installation

```bash
git clone https://github.com/SachinDevarajan/RestFramework.git
cd RestFramework
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Configure PostgreSQL in `settings.py` before running migrations.

## API Testing
Use Postman to test API endpoints and authentication.
